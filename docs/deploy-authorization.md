## 成本

- **HeyGen**：按成片分钟计费，售价 $4.83/分钟（Avatar IV），便宜档 $0.99/分钟（Avatar III）。验收大约 2 单 × 不到 1 分钟，**成本 < $6**。HeyGen API 额度会过期（旧文档写的是 12 个月），按量预充。
- **验收生成**：图片 1–2 张、最短视频 1 条，按 lanehub 现价计费，金额很小。
- **R2**：案例 561 张原图 + 两档缩略图，加上旧图复制一份（旧对象保留）。存储增量取决于旧归档数量，按量计费，预计很小；出网免费。
- **镜像**：ffmpeg 增加约 107MB（压缩）/ 210MB（磁盘）。服务器磁盘需要留 ≥ 2GB 余量。
- **内存**：网关上限 +256MB（768m），实际常驻增加量主要来自缩略图任务（通常 < 150MB）。
